Ecosystem

Built around OpenUI5

A rich set of official tools and community projects — everything you need from day one.

UI5 CLI
Build and serve any UI5 project — the primary development toolchain.
→ github.com/UI5/cli
UI5 Web Components
Framework-agnostic SAP Fiori components — use with React, Vue, Angular, or plain HTML.
→ github.com/UI5/webcomponents
UI5 Inspector
Browser DevTools extension for debugging and inspecting UI5 applications.
→ github.com/UI5/inspector
UI5 Linter
Catch UI5-specific errors and deprecated API usage before they ship.
→ github.com/UI5/linter
TypeScript Support
Official type definitions and tooling to build OpenUI5 apps in TypeScript.
→ github.com/UI5/typescript
UI5 MCP Server
Gives AI coding agents structured knowledge of OpenUI5 to generate better code.
→ github.com/UI5/mcp-server
