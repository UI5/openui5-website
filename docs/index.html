Empowering your app development

  • UI Controls

    OpenUI5 comes with a wide variety of controls ranging from basic input elements and buttons to more complex components like tables, object pages and trees. All of these controls offer best-in-class Accessibility and following the SAP Design system.

  • Internationalization

    All UI controls contained in OpenUI5 offer localized texts for more than 50 languages. Furthermore, OpenUI5 makes it quite easy to create translatable applications right from the start.

  • Programming Model

    OpenUI5 follows a modular, MVC (Model View Controller) - based architecture ensuring well defined project setups also for more complex scenarios.

  • Theming

    The visual appearance of OpenUI5 is handled by themes. OpenUI5 contains themes following the current SAP design system. Furthermore, it's possible to customize the visual appearance to match the branding and style requirements. Theming can be achieved through the use of the SAP Theme Designer or by custom CSS.

  • Data Binding

    OpenUI5 offers powerful data binding capabilities. By that it's such easy to automatically update UI controls when the underlying data model changes. This makes it easier to handle dynamic data and keep the UI in sync with data sources.

  • Tools

    UI5 offers a wide range of tools to make the daily life of an UI5 developer as productive as possible.

    • UI5 CLI: A command line interface to serve and build UI5 projects efficiently
    • UI5 linter: A tool to ensure your UI5 project follows current best practices
    • UI5 MCP server: The tool to choose in case your AI agent needs UI5 expertise
